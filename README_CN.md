# 体彩二串一模拟研究 PWA（Windows 10 制作版）

## 1. 项目说明
这是一个可安装到 iPhone 主屏幕的 PWA 网页应用。Windows 10 用于编辑、预览、打包和部署；iPhone SE3 与 iPhone 14 使用 Safari 安装。每台设备的 IndexedDB 数据彼此独立，不做 iCloud 同步。

**本版本是可运行的本地研究原型，不是已接入官方数据的完整自动化系统。** 不包含中国竞彩网官方实时接口、官方赛果自动核验、体彩特殊结算规则、经过训练/回测的 AI 模型。不会生成虚构赛程、赔率或结果。

## 2. Windows 10 本地预览
1. 解压 ZIP 到普通文件夹。
2. 安装 Python 3（可从 python.org 获取；安装时勾选 Add Python to PATH）。
3. 双击 `启动本地预览.bat`。
4. 浏览器打开 `http://127.0.0.1:8000` 预览。

本地预览只用于 Windows 电脑查看。iPhone 不能把 Windows 的 localhost 当成网站地址；局域网 HTTP 也不满足可靠 PWA 安装及 Service Worker 的 HTTPS 要求。

## 3. 发布到 HTTPS 后安装 iPhone
把整个文件夹中的文件上传到你控制且启用了 HTTPS 的静态网站托管空间（例如 GitHub Pages、Cloudflare Pages 等）。部署时网站根目录应包含 `index.html`、`app.js`、`sw.js`、`manifest.webmanifest` 和 `assets` 文件夹。确保 HTTPS 地址可公开访问或在你的设备上可访问。

在每台 iPhone 上分别操作：
1. 用 Safari 打开 HTTPS 网站地址。
2. 等页面加载完成，点 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”，确认添加。
4. 从主屏幕图标启动应用。
5. 进入“设置”或“概览”，按需启用通知（iOS 通知支持与系统版本、添加到主屏幕状态有关）。

iPhone SE3 和 iPhone 14 分别安装一次。它们的数据保存在各自设备，不会自动互通。定期在“概览/模拟记录”导出 CSV 备份。

## 4. 导入数据格式
在“数据导入”页导入 JSON。顶层可以是数组，也可以是 `{ "matches": [...] }`。每条记录至少需要 `id`、`source`、`capturedAt`；模拟筛选还要求 `probability`（0 到 1）和 `odds`。推荐字段：
- `id`：赛事稳定唯一编号
- `date`：开赛时间（含时区）
- `home`、`away`：球队
- `market`：模拟选项
- `odds`：对应赛前赔率
- `probability`：该选项赛前概率（0–1）
- `source`：数据来源名称
- `capturedAt`：赔率/概率快照采集时间

必须确保导入的是赛前数据，避免赛后信息泄漏。遵守数据源条款、访问频率与访问控制。不得绕过验证码、登录、付费墙或反爬措施。

## 5. 模拟规则（演示基线）
- 单场概率 ≥ 0.58
- 概率 × 赔率 ≥ 1.02
- 赔率 ≤ 4.00
- 选前两场构成一组虚拟二串一，虚拟投入 ¥10
- 不足两场合格赛事则空仓
- 理论模拟回报仅作算术展示，不等于真实奖金或实际可兑付金额
- 中奖率只按已结算记录计算；当前版本没有自动结算流程，所有组合保持“待核验”，因此中奖率通常显示“—”

## 6. 自动任务与通知限制
PWA 不具备可靠的 iOS 每日后台定时执行能力。网页关闭、系统省电或浏览器回收进程后，任务不会保证运行。此版本需打开应用后手动点“运行一次模拟”。通知只在浏览器/系统允许时尝试发送，不能作为后台任务准点完成保证。

如要实现真正稳定的每日 12:00 数据采集和次日赛果核验，需要一个合法运行的 HTTPS 后端定时服务与合规数据接口；这不可能仅靠 Windows 文件夹和 iPhone PWA 保证。

## 7. 数据与隐私
数据仅保存在当前浏览器 IndexedDB。清除 Safari 网站数据、移除站点数据或设备损坏可能造成数据丢失。请定期导出 CSV。没有云同步或服务器上传逻辑。

## 8. 故障排查
- Safari 不显示“添加到主屏幕”：确认使用 Safari、HTTPS 地址、页面加载成功。
- 离线打不开：先在线访问一次，等待 Service Worker 缓存完成。
- 通知不出现：检查 iOS 通知权限；PWA 通知支持受系统版本及安装方式影响。
- 导入失败：检查 JSON 格式、字段名和必需字段。
