数据格式示例

{
  "matches": [{
    "id": "match-001",
    "date": "2026-11-18T19:35:00+08:00",
    "home": "主队",
    "away": "客队",
    "market": "胜平负",
    "odds": 2.10,
    "probability": 0.60,
    "source": "公开数据来源名称",
    "capturedAt": "2026-11-17T12:00:00+08:00"
  }]
}

probability 为所选模拟结果的赛前概率（0–1）；odds 为对应赔率。请保留数据来源和采集时间。

筛选基线
